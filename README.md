# Timmy – Endless Runner

A 3D endless runner game developed using **Unity and C#**. The player controls Timmy, navigates through obstacles, and tries to achieve the highest possible score while the level continues generating ahead.

## 🎮 Gameplay

The objective is to survive as long as possible by avoiding obstacles and reacting to challenges along the way.

## ✨ Features

- **Player Movement:** Control Timmy through the game environment.
- **Obstacle System:** Avoid obstacles while running.
- **Endless Level Generation:** Continuously generate platforms or environment sections as the player progresses.
- **Collision Detection:** Detect collisions with obstacles and trigger the appropriate gameplay response.
- **Scoring System:** Track player progress and score.
- **Game Over System:** End the run when the player hits an obstacle.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open **Unity Hub**.
3. Select **Add Project from Disk**.
4. Choose the cloned project folder.
5. Open the project using a compatible Unity Editor version.
6. Open the main gameplay scene from the `Assets/Scenes/` folder.
7. Press **Play** in the Unity Editor to start playing.
